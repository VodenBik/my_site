Website

Poolsun

Corporate website for a company designing, installing and maintaining swimming pools.

TildaUI designCorporateDevelopment
ClientPoolsun
TaskCorporate website
ToolsTilda · Figma
Year2025

Task

The brief

Create the Poolsun website as a clear showcase of an engineering company. The page should quickly explain what the team does, why it can be trusted, and how to submit a request without unnecessary searching on the site.

Solution

Page logic

The structure is built around trust: clear positioning on the first screen, directions of work, visual examples, quality arguments and a clear path to contact. The visual style is based on large typography, a dark base and photographs of water, so that the site looks collected, technologically advanced and more expensive than typical contractor pages.

Visual system

Strict technological style

Process

How the structure was assembled

First, the logic of the page was collected: what the company does, what objects it employs, how it differs from competitors, and where the user should leave a request. After this, the structure was transferred to Tilda and refined through visual blocks, adaptation and neat accents in the interface.

Result

Outcome

The result was a solid presentation page for a swimming pool company: without unnecessary decorative noise, without repeating the cover and without undersized previews. The images are shown large, and the text guides users from understanding the service to submitting an enquiry.
